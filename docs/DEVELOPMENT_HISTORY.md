# 物理器械室 · 交互教学

2026-10-21 物理复核：修正转矩与绕组、接触通路、绳长守恒、液位/浮力、机构穿模及制冷管路追踪等问题。具体缺陷、验证范围和教学近似见 [物理与几何纠正复核](qa/PHYSICS-AUDIT.md)。原交互验收不等于物理正确性证明。

首页是一张白色网格器材地图，按热学、电与磁、机械、流体组织十五件成品模型。悬停约 300ms 出现圆角运行视窗，可移入、暂停和进入教具；同时只保留一个预览场景。支持分类、搜索、地图缩放和平移。手机使用双列器材列表，点按预览后进入。模型页面沿用蓝白控件、立体模型与课堂白板，左上角可返回首页。

建议通过下方本地服务打开，以保证首页与预览之间的同源控制可用。`engine.html` 为汽油机，冰箱和空调地址不变。首页内嵌十五张成品图，按需载入实际模型运行；各模型页面内嵌3D引擎、样式、教学模型与白板，不需要网络字体或CDN。模型使用支持WebGL2的Chrome/Edge。

开发与本地预览：

```powershell

```

打开 http://127.0.0.1:4198/ 。修改源文件后运行 `node build.mjs`；首页与十五个设备HTML都是生成文件。新首页源为 `map-home.source.html` / `map-home.css` / `map-home.mjs`。原弧线首页源保留作历史资料。

## 汽油机交互

- 立体剖面：整体、半剖、总成拆解、透视；选择部件高亮与查看讲解。
- 连续过程：暂停、慢放、下一冲程、0–720° 拖动；同一个几何模型驱动运动与阶段状态。
- 播放、模型方式和白板入口使用蓝白控件。播放按钮在“开始／暂停／继续”间保持大小；模型下方同步显示四冲程进度。运转时部件标注保留名称，暂停后显示测量数值。
- 三台器材统一使用立体模型，已移除纸上结构切换栏、SVG加载与相关入口；旧白板记录恢复时使用立体视图。
- 部件名称与说明只由点击模型或部件列表触发。进入、组装和播放循环不自动选中部件；点击模型区空白处取消选择，拖动空白处旋转视角保留选择。开始演示清除此前选择，白板可恢复用户保存的选择。验证：`node qa/click-only-selection.mjs`。
- 鼠标拖动旋转、滚轮缩放；触屏单指滑动页面，双指旋转缩放。页面提供还原、放大、缩小按钮。
- 键盘：Tab 遍历按钮；角度条用方向键调节；视图标签用左右键切换；模型聚焦时空格播放/暂停、左右键步进、R 还原。
- 首次进入用约4秒完成8步组装入场，部件连续落位，结束后自动运行；底部可暂停、跳步、重播或直接看完整结构。
- 顶部四个章节入口已移除。右上“构造与冲程”展开灰蓝色圆角浮卡，分为“认识构造”“四个冲程”，模型保持原尺寸。构造页选择部件；四冲程页包含冲程选择、播放、角度、速度、状态与能量说明。
- 浮卡从上向下展开，用240ms的clip-path、透明度与少量位移过渡；快速重复点击可反转，键盘与减弱动效模式即时开合。打开卡片会暂停入场；切到四冲程或选部件后显示完整模型。卡片内“重播入场”可重看组装。
- 课堂白板：保持真实模型，暂停教学时钟；可切换模型旋转和画笔、荧光笔、橡皮、文字、直线、箭头，支持撤销、重做、清空。桌面模型偏左，右侧留出板书空间。
- 板书保存在当前浏览器；本地板书可恢复对应教学时刻、模型视角和笔迹。它们属于屏幕上的批注，转动模型会改变与结构的相对位置。清理浏览器数据会失去板书；保存失败会明确提示。
- 系统要求减弱动态效果时，初始模型静止。点击组装后每步直接落位，用“下一步”查看，不自动滑入或试运行。
- 组装次序用于讲清构造和连接关系，不等同于制造或维修中的真实装配工艺。

## 冰箱与空调

2026-10-21：焦耳实验和气体实验台已从首页、导航及构建中移除，对应入口返回404。此前研究源文件、截图和导出素材保留作历史资料，不再构建发布。

两台制冷设备沿用汽油机的白色实验台和浮动控制条。约4秒内部优先、外壳最后的入场结束后，切换透视并自动循环。点击拆解后暂停，按功能总成展开；按住零件旋转，切换“移动”调整位置，点击“零件归位”恢复该总成。名称和功能只在白底小窗显示；“组装运行”从当前姿态平滑装回。进入白板时冻结动作。减弱动效模式不自动播放。

拆解控制器为 `engine-exploration.mjs`，设备展开配置为 `cooling-exploration.mjs`，统一外观为 `white-lab.css`。空调拆解时淡出连接铜管、保温套与排水长管，保留完整换热器盘管和接水盘。两套外壳上下居中，过滤网、换热器、风轮、风扇、压缩机排在两侧，共八个可独立操作的总成；导风板和接水盘随贯流风轮，阀件及气液分离器随压缩机。装回后恢复完整回路，冷暖切换及运行演示保持不变。`node qa/ac-centered-layout.mjs` 检查默认拆解视角的总成投影间距和移动端入镜。

冰箱拆解精简为五个可独立操作的总成：箱体、门、蒸发器、冷凝器、压缩机。连接铜管、毛细管长引线、温控感温引线在展开时淡出，装回时恢复；换热器自身的盘管与翅片保留。过滤器和毛细管卷跟随冷凝器，温控器跟随箱体，旋转、移动、归位与白板恢复都维持相对位置。专项验证：`node qa/fridge-clean-assemblies.mjs`。

冰箱默认展开布局以箱体为中央参考，左侧为蒸发器和冷凝器，右侧为门和压缩机。`node qa/fridge-centered-layout.mjs` 检查 390 / 820 / 1280 / 1440px 视口下各总成投影边界不重叠、箱体居中及模型完整入镜；自由转动视角或移动部件后，遮挡关系随观察角度改变。


- 电冰箱：保温箱体、箱门、蒸发器、冷凝器、压缩机、过滤干燥器、毛细管、温控器与密闭管路。按直冷式教学结构绘制。
- 空调：室内机过滤网、翅片换热器、贯流风轮、导风板与接水盘；室外机风扇、换热器、压缩机、四通阀、双向节流装置与气液分离器。切换制冷/制热，交换室内外换热器的任务，压缩机吸排方向保持不变。
- 五步、约4秒组装入场，结束后进入透视并自动运行；整体、剖切、拆解、透视可切换；点击部件定位讲解。
- 循环按压缩、冷凝、节流、蒸发分为四个观察环节。所有部件同时工作，16秒进度是跟踪一段制冷剂，而不是整机依次启停。可播放、暂停、跳环节、拖动、改变教学速度。
- 压缩机吸入与排出均为气体；冷凝放热液化；节流出口是气液混合物；蒸发吸热后回气。颜色是定性提示，不显示伪造的温压、制冷量或耗电量。风扇与导风板运动按观察进度确定，不代表实际转速。
- 三台机器的板书分别保存在本机浏览器；恢复时带回教学进度、冷暖模式、结构方式与相机，避免把另一台设备的板书套到当前模型。

## 源文件

`engine.source.html` / `style.css` / `app.mjs` 是汽油机界面；`whiteboard.mjs` / `whiteboard.css` / `whiteboard-store.mjs` 为白板；`model.mjs` 为纯运动学与教学数据；`anatomy.mjs` 为已停用的历史结构图源文件；`machine.html` / `machine-scene.mjs` 为立体场景。`build.mjs` 将全部功能打包。
