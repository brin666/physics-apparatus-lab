# 热能实验室 · 白色网格改版验收

2026-10-15，本地地址：http://127.0.0.1:4198/?v=white-grid 。

实现：按 design/white-grid-v1 的两张稿改版。标题为“热能实验室”，白底浅网格、近通栏大模型、说明默认收起、四个教学章节与底部短说明/播放进度。初始为270°压缩剖面；组装从“逐步组装”章节进入。

课堂白板使用同一实时模型；进入后暂停教学时钟，大屏偏左、右侧留板书空间，手机居中。画笔、荧光笔、整笔橡皮、文字、直线、箭头、颜色粗细、撤销重做与清空均可操作。板书保存在当前浏览器；历史页恢复角度、组装步骤、模型显示方式、相机和笔迹。绘图前清除旋转惯性，跨模式恢复同时恢复展示状态，防止视角漂移。

验证：

- npm.cmd run build：通过，单文件离线构建包含3D、结构图、白板及样式。
- npm.cmd test：12/12通过，覆盖机械几何、四冲程、点火、组装、板书存储及失败处理。
- npm.cmd run qa：通过，详见 redesign-results.json。覆盖八步真实组件显示、暂停、四种模型方式、结构图、能量章节、白板实际绘图及旋转、刷新后历史恢复、跨模式稳定相机、3D/纸图历史控件同步、组装后仅试运行一循环、390px无横向溢出、离线无外部请求和减弱动态效果。
- 独立Reviewer复核：首次打开270°压缩剖面；3D与纸图历史切换时相机工具/手势提示同步。已解决复核发现的问题。
- 最后针对性检查：修复模型工具原有的双重淡入，手机首次加载及白板中的选中标注完整显示；隐藏部件仍隐藏标注。见 label-check.mjs。
