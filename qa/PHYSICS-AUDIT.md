# 物理与几何纠正复核 · 2026-10-21

本次针对用户指出的模型错误，重新检查连接、转动净空、接触状态、液位和守恒关系。前一轮交互冒烟测试不能证明物理建模正确；本报告取代此前“未发现实质缺陷”的泛化结论。

## 已纠正的实质问题

| 器材 | 原问题 | 修正与直接证据 |
|---|---|---|
| 直流电动机 | 线圈绕自身法线旋转，不能产生画面中的轴向转矩；绕线穿轴 | 重建含轴向导体的连续线圈、换向器与绝缘引线；全周洛伦兹力方向、转子对磁极和轴净空测试 |
| 动圈扬声器 | 篮架坐标缺项、音圈骨架实心穿磁柱、纸盆朝向和引线不正确 | 环形磁隙、空心骨架、完整篮架、形变悬挂与分开的软引线；最大振幅网格检查 |
| 电磁继电器 | 固定与活动触点不接触，行程中显示仍导通 | 触点位置由同一衔铁转角驱动，NC/NO实际端位相切，转移期间两端断开 |
| 发电机 | 转子穿磁极/轴，引线与滑环关系不清 | 重做绕组与净空、两只独立滑环和绝缘跨环引线；感应电动势核对实际面积磁通的时间导数 |
| 电磁炉 | 锅沿平面错误、锅具未贴面板、磁通回路不闭合；移走锅仍显示运行 | 水平开口锅腔、真实板面接触、闭合穿锅底磁通示意；无锅停止驱动 |
| 金属箔验电器 | 接地/断地过程与箔片张角不符；接触与接地线状态矛盾 | 修正极化、接触、接地、断地、移棒与放电步骤；相对电荷守恒及实际可见性检查 |
| 滑动变阻器 | 滑片未真正接触绕组，导电通路不连续 | 螺旋绕组、顶部导电滑靴、37个真实接点；接入端与有效长度一致 |
| 滑轮组 | 绳子穿轮/脱离轮缘、总长随运动改变、绕向错误 | 公切线和半圆组成绳路；全程绳长守恒、两段承重、正确无滑动转角 |
| 潜水艇教学模型 | 显示的排水几何与浮力不一致，水覆盖舱内，负浮力停在任意深度；变压载时位置跳变 | 使用明确体积的方形教学舱；按实际浸没体积、重力、阻力和触底约束积分运动，联立外水与压载水守恒；手动改水量保持位置/速度，白板保存并恢复动态状态 |
| 船闸 | 门未开完船已穿门，液面与水路不连续 | 完全开门后通船；闸门互锁、统一水底和水面、涵洞下穿闸门 |
| U形管压强计 | 深度/液柱差使用不一致的比例，液体与管道错位 | 实际可见深度与液柱差满足静水压关系，极限输入不再错误夹紧液柱 |
| 活塞式抽水机 | 活塞无真实阀孔，传动/管路相交，水未到出口 | 真实阀孔/杆孔/侧孔、连续水路、固定支架、开口横槽传动；零速保持当前姿态 |
| 汽油机 | 闭合曲轴箱顶圈挡住连杆，底座/端盖进入运动空间 | 开放喉口、空心缸颈、带轴孔的端盖和修正底座；720°内每2°检查实际运动网格顶点对曲轴箱实体 |
| 电冰箱 | 示踪路径的弯曲半径与实体铜管不同 | 管路与示踪共用弯道半径；8条可匹配实体管路逐点核对中心线 |
| 空调 | 风轮缺少连接轴、穿接水盘，室外扇叶碰固定护网、支架悬空 | 补传动轴和支承，接水盘置于换热器下方、风轮上方；完整贯流轮扫掠包络对固定件保守间隙至少9.6mm；后移室外扇叶保证护网间隙；制冷/制热11条实体管路的追踪路径一致 |

公共运行层修正：条件隐藏不再被显示循环强制覆盖；电动机、发电机、扬声器、抽水机改变速度时保存相位；验电器自动循环必须经过明确放电步骤。

潜艇将操作演示时钟与连续物理时钟分离；动态读数来自当前模型状态。新增连续四周期逐帧检查、30/120 fps轨迹对照、暂停/手动调参/白板快照恢复，避免只校核静态公式。

## 教学依据与边界

各组依据与简化写在 `apparatus/*-notes.md` 和页面“构造与原理”中。原理来源、本站建模与教材逐页对应是三件不同的事，本次没有把通用原理资料冒充最新教材核验。

- 汽油机四冲程：[NASA Internal Combustion Engine Stages](https://www.grc.nasa.gov/WWW/K-12/airplane/engstage.html)、[NASA Otto Cycle](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/internal-combustion-engine-otto-cycle/)。模型仍省略配气驱动、润滑和燃烧动力学。
- 制冷循环：[Danfoss The fridge — how it works](https://www.danfoss.com/en/about-danfoss/our-businesses/cooling/the-fridge-how-it-works)、[DOE Heat Pump Systems](https://www.energy.gov/energysaver/heat-pump-systems)。管路是教学布置，不模拟真实温压、效率或制冷量。
- 电磁场线、相对电荷与若干慢放动作属于定性示意；潜艇使用有明确排水体积的方形教学舱；泵使用无损理想上限。它们服务课堂理解，不是产品设计或维修仿真。
